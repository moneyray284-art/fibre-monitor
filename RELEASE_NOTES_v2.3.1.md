# LinkWave v2.3.1

This stable patch release packages the current LinkWave feature set with updated version metadata.

## What's included

- Home Connection Check summarizes optical fibre health, Wi-Fi band balance, and latency/speed.
- Connection Diagnosis has three checks: Optical Fibre Line, Wi-Fi Band Balance, and Latency & Speed. The Wi-Fi row opens Wi-Fi settings, and Run Test starts Speed Test on Home.
- Clients can be filtered and sorted by Default, Strongest, or Lowest RSSI, with neutral Strong/Fair/Far signal labels.
- Client RSSI readings do not create connection alerts or appear in diagnostic summaries.
- Live router rates, optical receive power, household usage history, Wi-Fi controls, router profiles, appearance themes, and alternate app icons remain available.
