# LinkWave v2.3.2

This update improves daily usage history, Home profile persistence, and live speed display.

## What's new

- Completed past usage days no longer appear partial after ordinary overnight gaps.
- Usage Forecast now calculates daily average and projected monthly usage as soon as enough recorded past days are available.
- Home's usage and connected-device summaries are polished, and profile photos persist using a relative Application Support filename.
- Live Download and Upload digits render cleanly during speed updates without stacked numeric-roll effects.
- When Speed Test moves from Download to Upload, the Gateway Download readout smoothly returns to live router traffic while the Speed Test card retains its measured Downlink result.

## Included features

- Huawei ONT monitoring with live router rates, optical receive power, and internet speed testing.
- Router-based household usage totals and calendar-month history.
- Connected-device filtering, search, details, and available block/unblock controls.
- 2.4 GHz and 5 GHz Wi-Fi controls, router profiles, appearance themes, and alternate app icons.
